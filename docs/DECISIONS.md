# Decisions

- **2026-10-09 Stack.** TypeScript, Express 5, React 19 + Vite, SQLite via node:sqlite everywhere (tests use in-memory), Zod at the API boundary, Anthropic SDK with structured outputs (`output_config.format`) and `output_config.effort`. No Next.js, Supabase, job queue or ORM: one user, one process.
- **2026-10-09 Model.** Default `claude-opus-5-5`. Effort: `high` for everything by default (edits moved from `medium` on 9 Oct: on the rhyme-keeping brief E4, `high` gave more natural options for ~1 cent more; one sample, directional). Both adjustable in Settings. Rates snapshot in `server/engine/writer.ts` dated 2026-10-08.
- **2026-10-09 Literal edits skip the model.** "Change X to Y" with no creative words is applied directly (whole-word, case-sensitive first). Free, exact, recorded as `edit:direct`.
- **2026-10-09 Constraint checks.** Model reports constraints it read; a deterministic regex extracts counts and quoted start/end phrases; code validates. Failing options are shown with a ✗ label, not hidden, and not auto-repaired (no second paid call). Revisit if Sam finds this noisy.
- **2026-10-09 Spend.** Daily $10 / monthly $150 caps by default. Before each call the worst-case cost (max tokens × output rate) is reserved under a lock; actual cost from reported usage replaces it. Failures with unknown usage keep the reservation (counted, not assumed zero).
- **2026-10-09 Hosting.** Render web `0.5c-512mb` ($7) with a 1 GB disk ($0.25); ~$7.25/month. Data is one SQLite file (`node:sqlite`, built into Node 22) at `/var/data/songroom.db`, WAL mode, synchronous=FULL. PGlite was tried first and abandoned: it peaked at 650–860 MB on boot and Render killed it at 512 MB. SQLite boots at ~84 MB; verified data survives a hard kill. A separate Render Postgres ($6) was rejected because no existing paid database exists to share.
- **2026-10-09 Design.** Lyric pages are yellow legal-pad sheets (blue rules aligned to line height, red margin, blue-black ink, Newsreader); chrome is quiet graphite with Instrument Sans. Margin doodles stand in for illustrations.

- **2026-10-09 First live run (real Opus 5.5, prompt p1.0).** All 12 briefs succeeded, $0.33 total (ideas ~4c, lines ~2–4c, edits ~2c, literal edits free). Hard checks all passed. Weakest: E4 (rhyme kept by decorative words). Prompt p1.1 added rhyme guidance and quoted-word bans; E4 improved but is still the area to watch.
- **2026-10-09 API key.** Sam's key is multi-workspace, so requests send `anthropic-workspace-id` (Default workspace, org "Romans") via `ANTHROPIC_WORKSPACE_ID`.

- **2026-10-10 Prompt p2.0 is the default; the research pack is not.** The 9 Oct prompt (p1.1) forced every idea into a realisation story with a title twist and a domestic detail (audit: `research/PLAN.md`). p2.0 removes that, lets ideas take the shape the brief asks for, makes options lines-only, and tells the writer to admit an unknown reference instead of inventing it. p1.1 is kept verbatim as the baseline condition in Settings → Experiments. Craft notes from the research pack (`research/pack`) are behind the `craftPack` setting, off until Sam has judged the blind comparison.
- **2026-10-10 Research pack = JSONL files in the repo, keyword retrieval.** No vector store, no new service. `server/engine/pack.ts` loads `research/pack/*.jsonl` at boot and picks at most 2 cards + 2 reference profiles + 1 teaching pair by tag/keyword match (`PACK_LIMITS`). Sources are provenance only and never reach the writer. Each run records the prompt variant and the record IDs used (`runs.prompt_version`, `runs.request.pack`).
- **2026-10-10 Blind experiments.** `server/experiments.ts`: eleven fresh briefs × repeats × three conditions (A p1.1, B p2.0, C p2.0+pack), same model/effort/settings; outputs shuffled, conditions revealed only after a vote; $5 batch cap on top of the normal caps. Literal edits still skip the writer and are not part of the comparison.
